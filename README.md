# Word Siege 🏰

Hangman with a castle instead of a gallows. A word is hidden behind blanks;
every letter you get wrong is a boulder through your wall. The wall has to last
the **whole siege**, not just one word — so an early careless guess is still
costing you four words later.

**Play it here: https://rvenning.github.io/word-siege/**

## Features

- **18-siege campaign** across six realms — beasts, the royal kitchen, the
  castle keep, the wild lands, the stars and dragon country — with 144 words,
  each with its own clue.
- **The wall is the whole level.** Solve a word and the masons rebuild a block
  or two; by Dragon Peak there are no masons left and every mistake is
  permanent.
- **An armoury** to spend coins in: a Master Mason for a thicker wall, a Scout
  who reveals a letter at the start of every word, a Herald who shouts the clue
  for free, and a Repair Crew who rebuild faster.
- **Clues and reveals** mid-word for anyone who gets stuck, bought with coins
  earned defending earlier sieges.
- **Flawless streaks** — a word guessed without a single miss is worth a bonus
  that keeps growing while the run lasts.
- **Endless Siege** once nine sieges are won: words from every realm, hardest
  last, until the castle finally falls.
- Stars, a family leaderboard, and progress that follows you between devices.

## How to play

Tap a letter. If it's in the word it fills in — every copy of it at once. If it
isn't, the catapult fires and the wall loses a block. Guess the whole word to
send the masons out and bring on the next one. Lose all your blocks and the
castle falls.

A physical keyboard works too, on a laptop.

## Built on gamekit

Profiles + PINs, family sync, sound, screens, canvas effects and the install
prompt all come from [gamekit](https://github.com/rvenning/gamekit), vendored
into `lib/`. Re-vendor after a kit change:

```bash
node "../gamekit/tools/sync-to-game.js" "../word-siege"
```

## Layout

| Path | What's in it |
|---|---|
| `js/words.js` | The word bank — six realms x 24 words with clues, in three difficulty tiers |
| `js/levels.js` `js/upgrades.js` | Data registries: a new siege or a new upgrade is one entry |
| `js/game.js` | The siege engine. No DOM, no canvas, no audio — the test bot drives this exact code |
| `js/render.js` | The castle canvas: 13 wall pieces, catapult, boulders, rubble |
| `js/main.js` | Screens, campaign map, armoury, keyboard, results |
| `js/storage.js` | Save shape, cross-device merge, the coin ledger |
| `tests/` | Word-bank linter, headless balance bot, save-merge tests |

## PWA

`sw.js` (cache `word-siege-vN` — **bump it whenever a shell file changes**),
`manifest.json`, and `icons/` generated by `node tools/make-icons.js`.

## Local development

```bash
npx http-server . -p 8107 -c-1
```

Then open http://localhost:8107. Add `?debug=1` for the dev panel (jump to any
siege, solve the current word, smash a block — saving is disabled while it's
on).

## Tests

```bash
node --test
```

`tests/words.test.js` lints the whole word bank: A-Z only, the length band, no
duplicates, and no clue that gives its own answer away. `tests/bot.test.js`
plays all 18 sieges with a frequency-guessing bot and asserts each one is
winnable, none is trivial, and none can be won by guessing the alphabet in
order. `tests/storage.test.js` covers the coin ledger and the cross-device
merge. `node tests/bot.test.js --report` prints the per-siege numbers.

## Storage

`ws_*` in localStorage, Firestore collection `wordsiege` in the shared family
project. The Firebase config in `js/firebase-config.js` is a client key, not a
secret — it's restricted to the Cloud Firestore API.
